# Руководство администратора

## Установка

Запустите Docker Desktop и выполните `scripts/setup.ps1`, как указано в README. Первый запуск скачивает Python и PostgreSQL и устанавливает зависимости. Убедитесь, что `docker compose ps` показывает `healthy` для `app` и `db`.

Порт приложения — `127.0.0.1:8443`; порт PostgreSQL на Windows не публикуется. HTTPS обслуживается непосредственно Uvicorn с TLS 1.2/1.3. Для локального запуска автоматически создаётся самоподписанный сертификат. Для сетевого внедрения замените его доверенным сертификатом и настройте адрес/доступ; текущая поставка предназначена для локальной демонстрации.

`.env` содержит пароль БД, ключ JWT и первоначальный пароль администратора. Он исключен из Git и Docker build context. Значение `ADMIN_PASSWORD` используется только при создании пустой БД, его изменение не меняет существующий пароль.

## Пользователи

Войдите как администратор и откройте «Управление». Для создания пользователя заполните имя, фамилию, уникальный логин, пароль и роль. Логин состоит из 3–40 латинских букв, цифр, точек, дефисов или подчеркиваний. Пароль содержит не менее 8 символов, включая буквы и цифры. Пользователь сам создаст ключи при первом входе.

«Изменить» меняет сведения и роль; действующие токены становятся недействительными. «Заблокировать» закрывает вход и завершает сеансы. «Разблокировать» также снимает пятиминутную блокировку после неудачных попыток. «Завершить сеансы» отзывает все JWT пользователя. «Сбросить пароль» задает новый пароль и завершает все его сеансы, сохраняя зашифрованный закрытый ключ.

«Удалить» логически удаляет учётную запись и убирает пользователя из чатов. Идентификатор и логин сохраняются для связности истории и аудита; повторное использование логина не допускается. Отправленные ранее сообщения сохраняются у участников. Нельзя заблокировать или удалить самого себя, снять свои права либо оставить группу без активного администратора.

Администратор системы не получает доступ к чатам только благодаря своей роли. Просмотр сообщений требует обычного членства в чате; расшифрование требует закрытого ключа получателя.

## Журнал и обслуживание

Журнал показывает последние 300 событий: входы, ошибки входа, создание ключей, создание/изменение/удаление пользователей, блокировки, отзыв сеансов и изменения групп. В БД сохраняется весь журнал. Пароли, секретные фразы, закрытые ключи в открытом виде и содержимое сообщений туда не записываются.

Плановые работы согласуйте с пользователями за 24 часа. Сделайте резервную копию и остановите систему командой `docker compose stop`. Для возврата к работе выполните `docker compose up -d`. Перед обновлением сохраните каталог проекта, `.env` и резервную копию БД.

При ошибке запуска смотрите `docker compose logs --tail 100 app db`. Если порт 8443 занят, измените левую часть сопоставления порта в `compose.yaml` и открывайте новый адрес. Если недоступна БД, проверьте состояние `db`, свободное место и совпадение пароля `.env` с паролем существующего PostgreSQL volume.
