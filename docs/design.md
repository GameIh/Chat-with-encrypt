# Оформление мессенджера

За основу взят [Intercom в Refero Styles](https://styles.refero.design/style/12255b63-e506-4bc1-a4cd-d05487de32f3). Стиль адаптирован для интерфейса переписки.

Сохранена тёплая нейтральная палитра: фон переписки `#f8f7f4`, боковая панель `#f0eee9`, исходящие сообщения `#e9e7de`. Кнопка отправки имеет тёмный серо-зелёный цвет. Декоративных теней и градиентов нет.

Вместо верхней шапки с логотипом используется боковая панель: заголовок «Чаты», контакты, создание группы, поиск и список собеседников. Имя пользователя, состояние подключения и настройки находятся внизу. Буквенные логотипы, рекламные подзаголовки и повторяющиеся подписи о шифровании убраны. Сведения о ключах доступны в разделе «Мой ключ».

В личной переписке не повторяется имя автора у каждого сообщения. Дата показывается разделителем, время и статус — внизу сообщения. Действия «Ответить» и «Удалить» доступны через меню «⋯». Поле отправки содержит скрепку, текст и кнопку; имя файла появляется только после прикрепления.

Используется локальный Segoe UI с запасным Arial. Инициалы в списке обозначают людей, контурная иконка — группу. На телефоне список чатов и разговор отображаются отдельными экранами; стрелка в заголовке возвращает к списку.

Тема определена в `app/static/style.css`. Изменения затрагивают представление; API и криптографический протокол остаются прежними.
